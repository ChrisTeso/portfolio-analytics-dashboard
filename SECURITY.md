# Security and privacy

This repository is a demonstration application that uses deterministic synthetic data only.

- It does not connect to brokerages, banks, exchanges, or third-party APIs.
- It does not read cookies, browser profiles, keychains, environment secrets, or local financial files.
- It does not include real trades, account balances, screenshots, cached responses, credentials, or session artifacts.

Please report a suspected vulnerability through GitHub's private vulnerability reporting feature rather than a public issue.
